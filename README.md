# NestOra — Real Estate Discovery Platform

### A frontend-driven real estate experience focused on property discovery, responsive composition, and purposeful interaction.

NestOra is a real-estate web experience built from scratch with the goal of making property discovery feel structured, visual, and intuitive.

Rather than treating the project as a static landing page, the interface is designed around how a user actually explores properties — scanning listings, comparing information, navigating sections, and interacting with the interface across different screen sizes.

##  What I Built

- **Property Discovery Interface** — Property information is organized into visually distinct cards and sections so users can quickly understand location, pricing, area, and other key details.
- **Responsive Layout System** — The interface is structured to remain usable and visually consistent across desktop, tablet, and mobile viewports.
- **Interactive Experience** — JavaScript powers user interactions and dynamic interface behavior instead of relying solely on static markup.
- **Purposeful Motion** — Frontend motion and transitions are used to guide attention and improve the browsing experience rather than being added purely for decoration.
- **Reusable UI Patterns** — Common visual structures are kept consistent across the interface to maintain hierarchy and reduce unnecessary repetition.
- **Asset-Driven Presentation** — Property imagery and supporting visual assets are integrated as part of the overall information hierarchy.

##  Engineering Focus

### Responsive design is treated as a system

The interface was built with responsive behavior in mind from the beginning rather than creating a desktop layout and adapting it later.

### Visual hierarchy drives the interface

Property information is prioritized according to what a user needs to notice first, with layout, spacing, typography, and imagery working together to establish that hierarchy.

### Interaction has a purpose

Animations and JavaScript interactions are used to make navigation and discovery feel more natural while keeping the interface usable.

##  Built With

- **HTML5**
- **Tailwind CSS**
- **JavaScript**
- **PostCSS**

##  Project Objective

NestOra was built to move beyond basic frontend practice and demonstrate the ability to turn a real-world product concept into a polished, responsive interface.

The project focuses on **frontend engineering, responsive composition, interaction design, and visual problem-solving** rather than simply reproducing a static design.
